# Cannabis Legal

Landing page com os textos e as sete seções do HTML fornecido pelo usuário. As logos aprovadas estão em `dist/assets/`: a versão em perspectiva e a assinatura horizontal por Oyarzabal & Rostirolla. Preservar seu padrão tipográfico nas próximas revisões.

Página: `dist/index.html`. Aparência: `dist/assets/site.css`. Interações: `dist/assets/site.js`.

`source-content.html` preserva o arquivo recebido. `node build.mjs` recompõe a página a partir desse conteúdo. `node server.mjs` abre a prévia em http://127.0.0.1:4173.

Contatos não definidos: os botões informam que os canais serão disponibilizados em breve. Nenhum número ou e-mail provisório é usado como destino. O conteúdo jurídico foi preservado do documento fornecido, sem revisão jurídica neste trabalho de design.
